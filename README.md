# Pixel Flower Bloom

Um site interativo com uma flor pixel art que explode em emojis coloridos quando clicada! 🌹

## Recursos

- ✨ Flor pixel art animada
- 🎉 Efeito bloom com emojis dispersos
- 🔊 Som "plop" agradável
- 🌊 Background com efeito de ondas do mar em vermelho
- 🎨 Design limpo e responsivo

## Tecnologias

- React
- CSS3 Animations
- Web Audio API
